**稳定**表示该接入已随本版本发布。

表中能力的含义：

- **显存控制**：容器可申请的显存配额或分区规格。使用模板或固定规格时，显存按规格向上对齐。
- **计算资源控制**：各设备通过时间片、核心分配、硬件分区或 QoS 策略控制计算资源，具体限制见表中对应链接。
- **多卡切分**：同一容器跨多张物理设备分配资源，且可使用其中设备的部分资源。仅分配多张整卡不计为多卡切分，具体分配粒度和限制见对应链接。`不适用` 表示该模式仅分配整卡。

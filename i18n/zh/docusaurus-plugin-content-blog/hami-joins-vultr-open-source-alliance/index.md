HAMi 社区高兴地宣布，HAMi 已加入新成立的 **Vultr 开源联盟**（Vultr Open Source Alliance），成为其六家创始成员之一，其他创始成员还包括 Spinifex、Upbound、Qdrant、Valkey 与 NetBird。

[该联盟于 2026 年 11 月 10 日正式发布](https://blogs.vultr.com/vultr-open-source-alliance)，汇聚开源项目与基础设施提供商，帮助组织以生产级云基础设施的性能、规模与可控性来部署和运营开源技术。

<!-- truncate -->

## 让 GPU 基础设施更加开放与高效

随着 AI 工作负载持续增长，高效的 GPU 资源管理对构建和运营 AI 基础设施的组织而言愈发重要。

HAMi 是 CNCF 孵化阶段项目，通过在 Kubernetes 环境中实现 GPU 共享、资源隔离与异构算力调度来应对这一挑战。

通过允许多个工作负载在保持资源边界的前提下共享 GPU 资源，HAMi 帮助组织提升利用率，更充分地使用现有算力基础设施。

## Vultr 开源联盟的意义

Vultr 开源联盟将开源技术与云基础设施相结合，降低企业采用开源技术的门槛。

对 HAMi 而言，这为探索开源 GPU 资源管理与云 GPU 基础设施、Kubernetes 环境的结合创造了机会。

Vultr 的 Cloud GPU 与托管 Kubernetes 服务为探索面向 AI 应用的 GPU 共享、工作负载隔离与资源优化提供了合适的基础。

从更大的范围看，这次合作体现了双方对开放、可互操作、可移植基础设施的共同承诺，为开发者带来更大的灵活性与掌控力。

## 感谢 Vultr 对 HAMi 社区的支持

感谢 Vultr 长期以来对 HAMi 社区的支持。

Vultr 为社区提供了测试环境。在 [HAMi v2.11.0](/zh/blog/hami-v2-11-0-release) 发布期间，社区借助 Vultr 的云 GPU 测试环境完成了多项新能力的验证。这类支持让社区能够在真实基础设施上开展测试，也让开源开发与生产环境保持贴近。

## 展望

作为联盟的创始成员，HAMi 社区期待在技术协作上展开探索，包括部署指南、参考架构，以及帮助开发者评估和采用 GPU 共享技术的实用资源。

我们的目标没有改变：通过开源，让异构算力更易获得、更高效、更易管理。

我们欢迎与基础设施提供商、开发者以及更广泛的云原生社区协作，共同推进开放的 AI 基础设施。

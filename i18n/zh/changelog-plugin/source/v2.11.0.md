## 版本亮点

- 整卡分配不再挂载 HAMi-core，指标直接通过 NVML 导出。
- 支持 Cluster Autoscaler，并为 Flexible MIG 工作负载提供真实用量监控。
- 支持通过 Remote CUDA 运行 vLLM。
- 新增 PodGroup 调度、mutex 调度策略及策略组合，以及 GPU/CPU NUMA 对齐。
- 新增 AMD GPU 与昇腾 950 支持，并优化 libvnpu 性能。

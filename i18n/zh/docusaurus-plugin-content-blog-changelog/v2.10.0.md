## 主要功能

- 将 DRA 组件从 HAMi 主 Helm chart 中移除；Ascend DRA 支持迁移至独立的 [ascend-dra-driver](https://github.com/Project-HAMi/ascend-dra-driver) 仓库，作者 ([@archlitchi](https://github.com/archlitchi))，PR [#2038](https://github.com/Project-HAMi/HAMi/pull/2038)
- 新增 init container 支持，并正确进行 GPU 资源记账，作者 ([@maishivamhoo123](https://github.com/maishivamhoo123))，PR [#1773](https://github.com/Project-HAMi/HAMi/pull/1773)
- 新增 PodGroup（gang scheduling）支持，包括 Bind 阶段的 NodeLock 重试以及兼容 Kubernetes v1.36+ 的 gangScheduling feature gates，作者 ([@lin121291](https://github.com/lin121291)) 和 ([@archlitchi](https://github.com/archlitchi))，PR [#2066](https://github.com/Project-HAMi/HAMi/pull/2066) 与 [#2206](https://github.com/Project-HAMi/HAMi/pull/2206)
- 新增 Flexible MIG，支持 MIG 实例的动态分配与释放，作者 ([@FouoF](https://github.com/FouoF))，PR [#2378](https://github.com/Project-HAMi/HAMi/pull/2378)
- 新增 mutex GPU 调度策略，并支持逗号分隔的策略组合，作者 ([@mesutoezdil](https://github.com/mesutoezdil))，PR [#2011](https://github.com/Project-HAMi/HAMi/pull/2011) 与 [#2621](https://github.com/Project-HAMi/HAMi/pull/2621)
- 为 vGPU 副本新增可选的 NUMA 拓扑对齐（CPU 与 GPU），作者 ([@saiyam1814](https://github.com/saiyam1814))，PR [#2065](https://github.com/Project-HAMi/HAMi/pull/2065)
- 新增壁仞（Biren）设备支持，作者 ([@DSFans2014](https://github.com/DSFans2014))，PR [#1711](https://github.com/Project-HAMi/HAMi/pull/1711)
- 新增 AMD MI300x 系列 vGPU 支持，作者 ([@FouoF](https://github.com/FouoF))，PR [#2290](https://github.com/Project-HAMi/HAMi/pull/2290)
- 支持与模式无关的 Ascend Pod 跨 vNPU-template 与 HAMi-core 节点调度，作者 ([@ouyangluwei163](https://github.com/ouyangluwei163))，PR [#2035](https://github.com/Project-HAMi/HAMi/pull/2035)
- 新增 Ascend 910C vNPU 模板 vir05_1c_16g 与 vir10_3c_32g，作者 ([@ouyangluwei163](https://github.com/ouyangluwei163))，PR [#2005](https://github.com/Project-HAMi/HAMi/pull/2005)
- HAMi-core 模式下的 vNPU 不再将设备显存对齐到模板，作者 ([@archlitchi](https://github.com/archlitchi))，PR [#2696](https://github.com/Project-HAMi/HAMi/pull/2696)
- 将 HAMi-core 编译镜像切换为 ubi8，以支持所有 GLIBC 版本，作者 ([@spencercjh](https://github.com/spencercjh))，PR [#1958](https://github.com/Project-HAMi/HAMi/pull/1958)

## 主要 bug 修复

- 修复 MIG 失效问题，支持单 GPU 上的多个 MIG 实例，并在禁用 MIG 时跳过 nvidia-mig-parted，作者 ([@DSFans2014](https://github.com/DSFans2014))、([@saiyam1814](https://github.com/saiyam1814)) 和 ([@maishivamhoo123](https://github.com/maishivamhoo123))，PR [#1819](https://github.com/Project-HAMi/HAMi/pull/1819)、[#2724](https://github.com/Project-HAMi/HAMi/pull/2724) 与 [#1930](https://github.com/Project-HAMi/HAMi/pull/1930)
- 修复 MIG 使用量损坏与文件描述符泄漏，作者 ([@adity1raut](https://github.com/adity1raut))，PR [#2245](https://github.com/Project-HAMi/HAMi/pull/2245)
- 对从 UUID 注解解析的 MIG 模板与实例索引增加边界检查，作者 ([@mesutoezdil](https://github.com/mesutoezdil))，PR [#2088](https://github.com/Project-HAMi/HAMi/pull/2088)
- 通过 NVSwitch 检测 NVLink，修复拓扑评分，作者 ([@peachest](https://github.com/peachest))，PR [#2103](https://github.com/Project-HAMi/HAMi/pull/2103)
- 加固 HTTP 服务器与 migconfig 文件权限，作者 ([@mesutoezdil](https://github.com/mesutoezdil))，PR [#2100](https://github.com/Project-HAMi/HAMi/pull/2100)
- 修复节点锁处理：保留并发节点锁、回滚部分设备锁，并避免寒武纪节点锁泄漏，作者 ([@ShiroKSH](https://github.com/ShiroKSH))、([@AyushSrivastava1818](https://github.com/AyushSrivastava1818)) 和 ([@jianzhangbjz](https://github.com/jianzhangbjz))，PR [#2197](https://github.com/Project-HAMi/HAMi/pull/2197)、[#2626](https://github.com/Project-HAMi/HAMi/pull/2626) 与 [#2329](https://github.com/Project-HAMi/HAMi/pull/2329)
- Bind 失败时清理 podManager，避免资源泄漏，作者 ([@peachest](https://github.com/peachest))，PR [#1927](https://github.com/Project-HAMi/HAMi/pull/1927)
- 在节点使用量查询、节点管理器和 Pod 管理器中返回副本而非共享指针，修复数据竞争，作者 ([@DSFans2014](https://github.com/DSFans2014))、([@mesutoezdil](https://github.com/mesutoezdil)) 和 ([@AyushSrivastava1818](https://github.com/AyushSrivastava1818))，PR [#1967](https://github.com/Project-HAMi/HAMi/pull/1967)、[#2055](https://github.com/Project-HAMi/HAMi/pull/2055) 与 [#2333](https://github.com/Project-HAMi/HAMi/pull/2333)
- 修复 ResourceQuota 计账：负使用量归零、对所有设备后端强制配额、支持显式零限额，作者 ([@mesutoezdil](https://github.com/mesutoezdil))、([@Lakshya77089](https://github.com/Lakshya77089)) 和 ([@veyron-kairo](https://github.com/veyron-kairo))，PR [#1880](https://github.com/Project-HAMi/HAMi/pull/1880)、[#2347](https://github.com/Project-HAMi/HAMi/pull/2347) 与 [#2313](https://github.com/Project-HAMi/HAMi/pull/2313)
- 恢复带有过期 `Deleted_` 握手注解节点的调度，并按本地时区解析握手时间戳，作者 ([@saiyam1814](https://github.com/saiyam1814)) 和 ([@mesutoezdil](https://github.com/mesutoezdil))，PR [#1843](https://github.com/Project-HAMi/HAMi/pull/1843) 与 [#1816](https://github.com/Project-HAMi/HAMi/pull/1816)
- 校验 `gpumem-percentage` 取值范围，并将 0 视为未设置，避免静默不可调度，作者 ([@saiyam1814](https://github.com/saiyam1814)) 和 ([@Wangmin362](https://github.com/Wangmin362))，PR [#1997](https://github.com/Project-HAMi/HAMi/pull/1997) 与 [#2156](https://github.com/Project-HAMi/HAMi/pull/2156)
- 修复 vGPUmonitor 与调度器中的多个 panic 路径，包括 nil 请求体、零值除法和设备索引越界，作者 ([@devGPP23](https://github.com/devGPP23))、([@lin121291](https://github.com/lin121291)) 和 ([@Nakshatra480](https://github.com/Nakshatra480))，PR [#2384](https://github.com/Project-HAMi/HAMi/pull/2384)、[#1820](https://github.com/Project-HAMi/HAMi/pull/1820) 与 [#2400](https://github.com/Project-HAMi/HAMi/pull/2400)
- 修复多容器 Allocate 中的过期注解，作者 ([@peachest](https://github.com/peachest))，PR [#2380](https://github.com/Project-HAMi/HAMi/pull/2380)
- 修复 `memory_allocated_bytes` 指标的高基数泄漏，作者 ([@Aryanbhargava18](https://github.com/Aryanbhargava18))，PR [#2142](https://github.com/Project-HAMi/HAMi/pull/2142)
- 修复 chart 问题：`ld.so.preload` 从 `devicePlugin.libPath` 派生，全局镜像标签不再覆盖组件级标签，作者 ([@ilia-medvedev](https://github.com/ilia-medvedev)) 和 ([@FouoF](https://github.com/FouoF))，PR [#1714](https://github.com/Project-HAMi/HAMi/pull/1714) 与 [#1774](https://github.com/Project-HAMi/HAMi/pull/1774)

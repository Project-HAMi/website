**Stable** means the integration is included in this release.

Capability definitions:

- **Memory control**: The memory quota or partition size a container can request. Templates and fixed partitions round requests up to a supported size.
- **Compute control**: Devices control compute resources through time slicing, core allocation, hardware partitions, or QoS policies. The linked guides describe the corresponding limits.
- **Multi-card partitioning**: A single container can allocate resources across multiple physical devices while using only part of at least one device. Allocating multiple whole devices does not count as multi-card partitioning. See the linked references for allocation granularity and limits. `N/A` means the mode allocates whole devices only.
